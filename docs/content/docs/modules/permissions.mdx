# Permissions Module

**Replaces:** LuckPerms  
**Config Section:** `permissions`  
**Permission Prefix:** `pumpkin-unified-core.lp`

## Configuration

```toml
[permissions]
enable_contexts = true          # Enable context support
default_group = "default"       # Default group for new players
[permissions.inheritance]
max_depth = 10                  # Max inheritance depth
order = "depth-first"           # "depth-first" or "breadth-first"
permissions.tracks = []         # Promotion tracks
```

## Contexts

PUC supports LuckPerms contexts:

```bash
# World-specific permission
/lp user Steve permission set pumpkin-unified-core.fly true world=world_nether

# Server-specific (for proxy)
/lp user Steve permission set pumpkin-unified-core.fly true server=survival

# Temporary permission (time-based)
/lp user Steve permission set pumpkin-unified-core.fly true 3600

# Temporary with context
/lp user Steve permission set pumpkin-unified-core.fly true 3600 world=world_nether
```

## Examples

```bash
# Create groups
/lp creategroup default
/lp creategroup builder
/lp creategroup mod
/lp creategroup admin

# Set up inheritance
/lp group builder parent add default
/lp group mod parent add builder
/lp group admin parent add mod

# Set weights (higher = more priority)
/lp group default setweight 100
/lp group builder setweight 200
/lp group mod setweight 300
/lp group admin setweight 400

# Set permissions
/lp group default permission set pumpkin-unified-core.sethome true
/lp group builder permission set pumpkin-unified-core.gamemode.creative true
/lp group mod permission set pumpkin-unified-core.kick true
/lp group admin permission set pumpkin-unified-core.* true

# Create promotion track
/lp createtrack staff builder mod admin
/lp track staff append admin

# Promote user
/lp user Steve promote staff

# Add user to group
/lp user Steve parent add builder

# Set user permission
/lp user Steve permission set pumpkin-unified-core.fly true

# View user info
/lp user Steve info

# Search for permission
/lp search fly
```

## Tracks Example

```bash
# Create donor track
/lp createtrack donor vip mvp
/lp track donor append mvp

# Promote through track
/lp user Steve promote donor
# Steve: default -> vip -> mvp
```

## Storage

Permissions stored in:
- `users` table - User data
- `groups` table - Group data
- `tracks` table - Track definitions
- `logs` table - Change history

## Migration from LuckPerms

```bash
# Export from LuckPerms
/lp export file

# Import to PUC
/lp import file
```

Or use SQL migration for large datasets.

## Permissions Setup

```bash
# Permission managers
/lp group perms permission set pumpkin-unified-core.lp.user.info true
/lp group perms permission set pumpkin-unified-core.lp.user.editor true
/lp group perms permission set pumpkin-unified-core.lp.group.info true
/lp group perms permission set pumpkin-unified-core.lp.sync true

# Full admin access
/lp group admin permission set pumpkin-unified-core.lp.* true
```

## Notes

- Full LuckPerms API compatibility
- Contexts: world, server, global
- Inheritance: depth-first or breadth-first
- Tracks for promotion paths
- Web editor at `/lp editor`
