## Enabling/Disabling Modules

Disable modules by setting limits to 0 in config:

```toml
# Disable holograms
[holograms]
max_holograms_per_player = 0

# Disable portals
[portals]
max_portals = 0

# Disable scheduler
[scheduler]
enabled = false
```

Or remove permissions:
```bash
# Remove all hologram permissions from default group
/lp group default permission unset pumpkin-unified-core.hologram.*
```

## Performance Notes

- Each module loads on-demand
- Storage queries are cached with DashMap
- Async operations use Tokio
- Holograms/Portals use minimal entity tracking
- Scheduler uses efficient cron parsing
