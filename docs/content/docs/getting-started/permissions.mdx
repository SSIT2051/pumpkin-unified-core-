# Permissions

PUC uses a hierarchical permission system with the `pumpkin-unified-core.` namespace.

## Permission Structure

All permissions follow the pattern:
```
pumpkin-unified-core.<module>.<action>
```

## Default Permissions

| Permission | Default | Description |
|------------|---------|-------------|
| `pumpkin-unified-core.*` | Op | All PUC permissions |
| `pumpkin-unified-core.admin` | Op | Admin shortcut |

## Setting Up Groups

### Example: Default Group
```bash
/lp creategroup default
/lp group default permission set pumpkin-unified-core.balance true
/lp group default permission set pumpkin-unified-core.pay true
/lp group default permission set pumpkin-unified-core.warp true
/lp group default permission set pumpkin-unified-core.sethome true
/lp group default permission set pumpkin-unified-core.tpa true
/lp group default permission set pumpkin-unified-core.kit true
```

### Example: VIP Group
```bash
/lp creategroup vip
/lp group vip parent add default
/lp group vip permission set pumpkin-unified-core.homes.limit.10 true
/lp group vip permission set pumpkin-unified-core.kit.vip true
/lp group vip permission set pumpkin-unified-core.fly true
```

### Example: Admin Group
```bash
/lp creategroup admin
/lp group admin permission set pumpkin-unified-core.* true
```

## Assigning Players

```bash
# Add to group
/lp user <player> parent add vip

# Set specific permission
/lp user <player> permission set pumpkin-unified-core.fly true

# Remove permission
/lp user <player> permission unset pumpkin-unified-core.fly
```

## Contexts

PUC supports LuckPerms contexts for world-specific permissions:

```bash
# World-specific permission
/lp user <player> permission set pumpkin-unified-core.fly true world=world_nether

# Server-specific (for Bungee/Velocity)
/lp user <player> permission set pumpkin-unified-core.fly true server=survival
```

## Migration from EssentialsX/LuckPerms

Permission mapping is 1:1:
- `essentials.*` → `pumpkin-unified-core.*`
- `luckperms.*` → `pumpkin-unified-core.lp.*`

Use `/lp import` for bulk migration.
