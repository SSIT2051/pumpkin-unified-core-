# Configuration

PUC uses TOML and YAML configuration files with environment variable overrides.

## Config Files

| File | Priority | Description |
|------|----------|-------------|
| `config.default.toml` | Lowest | Built-in defaults (read-only) |
| `config.default.yml` | Low | Built-in defaults (read-only) |
| `config.toml` | Medium | Main configuration (edit this) |
| `config.yml` | Medium | Alternative YAML config |
| `PUC_*` env vars | Highest | Runtime overrides |

## Storage Backend

PUC supports multiple storage backends:

### SQLite (Default)

```toml
[storage]
backend = "sqlite"
[storage.sqlite]
path = "plugins/pumpkin-unified-core/data.db"
max_connections = 10
```

### Redis

```toml
[storage]
backend = "redis"
[storage.redis]
url = "redis://127.0.0.1:6379"
max_connections = 10
```

### MySQL/PostgreSQL

```toml
[storage]
backend = "mysql"
[storage.mysql]
url = "mysql://user:pass@localhost/pumpkin"
max_connections = 10
```

## Environment Variables

Override any config with `PUC_` prefix:

```bash
# Storage
PUC_STORAGE__BACKEND=redis
PUC_STORAGE__REDIS__URL=redis://localhost:6379

# Economy
PUC_ECONOMY__STARTING_BALANCE=500.0
PUC_ECONOMY__CURRENCY_SYMBOL="€"

# Disable modules
PUC_HOLOGRAMS__MAX_HOLOGRAMS_PER_PLAYER=0
PUC_PORTALS__MAX_PORTALS=0
```

## Hot Reload

Apply config changes without restart:

```bash
/puc reload
```

Or from console:
```
puc reload
```

## Validation

PUC validates config on load. Invalid values fall back to defaults with warnings in logs.
